# This is the repo part for the api of the project.

Para correrlo todo, se necesita docker, y en el dir de Backend correr ´docker compose up -d --build´
Va a instalar los requerimientos y correr todos los api al mismo tiempo.

En el caso de no correrlos con docker se puede correr con venv por cada proyecto. Dentro de cada folder hay un documento de ´requirements.txt´ con lo necesario para correrlos
